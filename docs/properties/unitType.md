# unitType

The temporal unit which provides the precision of a date-time value or scale of a temporal extent

**Domain**: [Duration](../classes/Duration.md) or [GeneralDateTimeDescription](../classes/GeneralDateTimeDescription.md)

**Range**: [TemporalUnit](../classes/TemporalUnit.md)

**IRI**: `http://www.w3.org/2006/time/unitType`
